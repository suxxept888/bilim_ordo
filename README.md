# Bilim Ordo

Уроки по высшей математике от реальных преподавателей внутри Telegram-бота.
Сейчас это только каркас: экраны и переходы, без уроков, рейтингов и аккаунтов.

## Что где лежит

- `webapp/` — мини-приложение, которое открывается внутри Телеграма
  - `index.html` — основа страницы и нижнее меню
  - `style.css` — оформление (цвета подстраиваются под тему Телеграма)
  - `app.js` — экраны и переходы между ними
- `bot/` — бот, который показывает кнопку «Открыть уроки»
  - `bot.py` — код бота
  - `requirements.txt` — что нужно установить для бота
  - `.env.example` — пример настроек (токен бота и адрес приложения)

## Экраны

| Экран | Адрес | Что на нём будет |
|---|---|---|
| Темы | `#catalog` | список тем по вышмату |
| Тема | `#topic` | уроки разных преподавателей по теме |
| Урок | `#lesson` | видео и текст урока |
| Преподаватели | `#teachers` | список преподавателей |
| Преподаватель | `#teacher` | профиль и его уроки |
| Загрузить урок | `#upload` | форма для преподавателя |

## Как посмотреть сейчас

Откройте файл `webapp/index.html` двойным щелчком: он откроется в браузере.
Внизу есть меню для переключения экранов.

## Что дальше (по вашему решению)

1. Наполнить темы и уроки.
2. Создать бота у @BotFather и разместить `webapp/` в интернете по ссылке https.
3. Рейтинги студентов и аккаунты преподавателей.
